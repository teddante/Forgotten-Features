# Feature Candidates

This is the tidy working list for possible Forgotten Features content.

Use `docs/allfeaturesfromwiki.md` as the raw reference archive. Do not edit the raw archive directly.

## Ranking Notes

Suggested priority:

- `high`: iconic, wanted, clear evidence, reasonable to implement.
- `medium`: useful or interesting, but needs more research or has more risk.
- `low`: niche, hard, unclear, or likely to cause compatibility problems.
- `maybe-later`: speculative, myth-like, or not worth doing early.

Suggested categories:

- Blocks and items.
- Mobs and AI.
- World generation.
- Structures.
- Mechanics.
- Visuals and sounds.
- Experimental or speculative.
